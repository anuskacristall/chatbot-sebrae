Instruções para Importação

  • Formato Válido: Apenas arquivos no formato .pdf são aceitos.
  • Texto Selecionável: O conteúdo textual deve ser selecionável (pesquisável). PDFs digitalizados como imagem (scans) não serão lidos pelo sistema.
  • Imagens: Imagens e gráficos são ignorados pelo leitor, apenas os textos escritos são processados.
  • Tamanho Recomendado: Para melhor desempenho da sincronização, envie arquivos de até 15 MB.
